// Role: ADMIN Architecture

Admin Management Console

Architectural workspace reserved for future modules. When activated, administrators will execute full CRUD operations against Local Storage to sync data directly to the public portfolio.

Projects Manager Reserved Module

Create, read, update, and delete featured project cards. Persists directly to portfolio_projects in Local Storage.

Key: portfolio_projects (CRUD)
Skills Manager Reserved Module

Adjust technical proficiencies, progress bar metrics, and category tags. Persists to portfolio_skills in Local Storage.

Key: portfolio_skills (CRUD)
Blog Articles Manager Reserved Module

Author and publish markdown articles, category tags, and reading times. Persists to portfolio_blogs in Local Storage.

Key: portfolio_blogs (CRUD)
Messages Inbox (Admin → Messages) Reserved Module

Review, mark as read, and manage client inquiries submitted through the public Contact form. Stored in portfolio_messages.

Key: portfolio_messages (Read/Delete)
